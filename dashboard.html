Required JSON Format

[ { "subject": "History", "type": "single", "text": "Who discovered America?", "options": ["Columbus", "Magellan", "Cook"], "correct": [0], "explanation": "In 1492." } ]
  • subject: Category of the question.
  • text: The question (supports Markdown/LaTeX).
  • options: Array of string choices.
  • correct: Array containing the correct index (e.g., [0]).
  • explanation: Optional explanation string.
